## Security Notes
⚠️ **Important:** This is a demo project. In a production environment:
- Never store passwords in plain text
- Use proper password hashing (bcrypt, argon2, etc.)
- Implement proper authentication with JWT or sessions
- Store credentials in a secure database
- Use HTTPS for all communications

## Usage
1. Navigate to `admin-login.html`
2. Use one of the email/password combinations above
3. Access the admin dashboard for content management
