# Cheesboy Fashion Web Page

A simple web page inspired by the Shein website design, featuring a modern e-commerce layout.

## Files

### Main Pages
- `index.html`: Main home page
- `women.html`: Women's fashion page
- `men.html`: Men's fashion page
- `kids.html`: Kids' fashion page
- `beauty.html`: Beauty products page
- `account.html`: Account page with login and signup forms

### Admin Pages
- `admin.html`: Redirect to admin login
- `admin-login.html`: Admin login and signup page
- `admin-dashboard.html`: Admin dashboard with management options
- `admin-adverts.html`: Advert management and upload page

### Assets
- `css/styles.css`: Styling for all pages (light theme with auto dark mode)
- `js/script.js`: JavaScript for main pages and theme switching
- `js/account.js`: JavaScript for account page tabs
- `js/admin-login.js`: JavaScript for admin login and signup
- `js/admin-dashboard.js`: JavaScript for admin dashboard (login check, logout)
- `js/admin-adverts.js`: JavaScript for advert management (upload, remove, list)

## Usage

1. Open `index.html` in a web browser to view the page.
2. The page includes a header with logo, search bar, and icons.
3. Navigation menu for different categories.
4. Hero section with call-to-action.
5. Categories and featured products sections.
6. Footer with links.

## Features

- Responsive design that works on mobile and desktop.
- Search bar (placeholder functionality).
- Add to cart buttons (alert on click).
- Hover effects on categories and products.

## Troubleshooting

- If images don't load, they are using placeholder images from via.placeholder.com.
- Ensure all files are in the correct directory structure.
- Open the page in a modern web browser for best results.

## Customization

- Edit `styles.css` to change colors, fonts, or layout.
- Modify `index.html` to add more content or sections.
- Update `script.js` to add more interactive features.
